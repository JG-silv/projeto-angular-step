# Aplicação Angular do curso STEP

Este é o workspace Angular usado nas aulas do repositório. A explicação do
funcionamento do Angular, dos exemplos até a Aula 3 e dos comandos para executar
o projeto está no [README principal](../README.md).

Para iniciar a aplicação no PowerShell:

```powershell
npm install
npm start
```

Em seguida, abra <http://localhost:4200/>.
